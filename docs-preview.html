StayBook API (1.0.0)

Download OpenAPI specification:

StayBook Developer Support: api-support@staybook.dev URL: https://developers.staybook.dev License: Portfolio sample — not for production use

The StayBook API lets partners search property availability, create and manage reservations, and receive real-time booking events via webhooks.

Base URL

All requests are made to https://api.staybook.dev/v1.

Conventions

  • All timestamps are ISO 8601 UTC (e.g. 2026-09-14T15:00:00Z).
  • All monetary amounts are in the smallest currency unit (e.g. cents) alongside an ISO 4217 currency code.
  • List endpoints are cursor-paginated. See Pagination.
  • Errors follow a single consistent shape. See Errors.

string <date>

integer >= 1

string
